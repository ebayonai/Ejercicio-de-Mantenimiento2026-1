Actividad con GitHub

¡Felicitaciones! Lograron llegar al repositorio. Ahora es momento de trabajar con HTML.

El siguiente paso es ingresar al archivo index del repositorio: 
 Ejercicio-de-Mantenimiento2026-1,  Allí encontrarán un ejemplo donde se realiza la suma de dos números.

Su tarea consiste en modificar ese archivo para convertirlo en una pequeña calculadora que permita realizar las siguientes operaciones:
•	Suma
•	Resta
•	Multiplicación
•	División
⚠ Tengan en cuenta que la división por 0 no existe, por lo que deben manejar ese caso en su código.
Pasos para subir el trabajo con GitHub Desktop
1.	Abrir GitHub Desktop.
2.	Ir al repositorio Ejercicio-de-Mantenimiento2026-1.
3.	Abrir el archivo index.html y realizar las modificaciones para crear la calculadora.
4.	Guardar los cambios en el archivo.
Crear una nueva rama (Branch)
5.	En GitHub Desktop, hacer clic en Current Branch.
6.	Seleccionar New Branch.
7.	Escribir el nombre de la rama con los códigos de los integrantes del equipo.
8.	Ejemplo: 190217-190218Calculadora
9.	Hacer clic en Create Branch.
Guardar y subir los cambios
10.	En la parte izquierda aparecerán los archivos modificados.
11.	Escribir un mensaje en Summary, por ejemplo: Calculadora con operaciones básicas.
12.	Hacer clic en Commit to 190217-190218Calculadora.
13.	Finalmente hacer clic en Push origin para subir los cambios al repositorio.
Verifiquen en GitHub que la rama creada aparece en el repositorio y que el archivo index.html contiene la calculadora funcionando.
